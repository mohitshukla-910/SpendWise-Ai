# SpendWise AI

SpendWise AI is a lightweight AI spending audit tool designed to help individuals and small teams analyze their AI subscription costs and identify potential savings opportunities.

## Features

- AI tool audit form
- Smart recommendation engine
- Monthly and yearly savings calculations
- Team-size based recommendations
- Responsive modern UI
- Built with reusable React components

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## How It Works

Users enter:
- AI tool
- subscription plan
- monthly spend
- team size

The audit engine evaluates the inputs and provides:
- cost optimization suggestions
- potential savings estimates
- smarter plan recommendations

## Example Recommendation

If a small team is using ChatGPT Team, the app may recommend switching to ChatGPT Plus to reduce unnecessary spending.
